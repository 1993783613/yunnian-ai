# 云念AI - 响应式网站

> 与想念的人，再通一次视频 —— 让思念留在云端，让陪伴继续。

基于云念AI 真实产品还原的 H5 移动端应用，包含完整的用户流程：创建数字人 → 实时语音/视频通话。

## 项目特点

- **完全还原真实配色**：深蓝黑背景 (#050913) + 青绿色品牌色 (#35e6d0)
- **真实文案**：所有界面文字均来自云念AI 真实产品（558条原文提取）
- **移动端 H5 布局**：桌面端自动以手机框架居中展示
- **11 个完整页面**：首页、登录注册、创作库、创建角色、通话、消息、我的、充值、隐私设置、用户协议、隐私政策
- **零依赖**：纯 HTML + CSS + JS，无需构建工具
- **响应式**：完美适配手机/平板/桌面

## 部署上线指南

### 方案一：Vercel（推荐，免费）

1. 注册 [Vercel](https://vercel.com) 账号
2. 安装 CLI：`npm i -g vercel`
3. 在项目目录执行：
   ```bash
   vercel
   ```
4. 按提示操作，完成后获得 `https://你的项目.vercel.app` 链接
5. 可绑定自定义域名

### 方案二：Netlify（免费，拖拽部署）

1. 访问 [Netlify Drop](https://app.netlify.com/drop)
2. 将整个项目文件夹拖入页面
3. 即时获得在线链接

### 方案三：腾讯云静态网站托管

1. 登录腾讯云控制台 → 静态网站托管
2. 创建环境，上传项目文件
3. 绑定自定义域名（需备案）

### 方案四：GitHub Pages

1. 创建 GitHub 仓库
2. 上传项目文件
3. Settings → Pages → Source 选择 main 分支
4. 访问 `https://用户名.github.io/仓库名`

### 方案五：阿里云 OSS

1. 创建 OSS Bucket，读写权限设为"公共读"
2. 上传项目文件
3. 绑定自定义域名 + CDN 加速

## 真实视频通话（腾讯云 TRTC）

通话页已接入真实的腾讯云 TRTC 音视频能力。工作流程：

1. 进入「创作库 → 亲人实时通话」→ 输入称呼 → **发起视频通话**
2. 系统生成 8 位房间号 + 邀请链接，把链接发给对方
3. 对方点开链接自动加入同一房间，双端实时音视频互通
4. 也可通过「通过房间号加入」直接输房间号进房

进房凭证 UserSig 由腾讯云函数签发，SecretKey 只存在于云函数环境变量，前端代码不含任何密钥。

### 云函数部署步骤（约 10 分钟）

部署包：`yunnian-usersig-scf.zip`（已含 index.js + 依赖的 node_modules，无需再装包）

1. 打开腾讯云函数控制台：`https://console.cloud.tencent.com/scf`
2. 【函数服务】→【新建】→ 按以下配置：
   - 函数类型：**事件函数**
   - 函数名称：`yunnian-usersig`
   - 运行环境：**Node.js 16.13**（或更高）
   - 创建方式：**使用模板函数 / 从零开始**（选从零开始）
   - 提交方法：**本地上传 ZIP 包** → 选择 `yunnian-usersig-scf.zip`
   - 环境变量（关键！在「高级配置」里添加）：
     | 键 | 值 |
     |----|-----|
     | `SDKAPPID` | `1600160855` |
     | `SECRETKEY` | 你的 TRTC 应用密钥（应用详情页复制） |
   - 执行超时时间：改为 **10 秒**（默认 3 秒太短）
3. 创建完成后，进入函数详情 →【函数 URL】或【触发器】→ 开启**公网访问 URL**（免鉴权）
4. 复制函数 URL，填入 `js/config.js` 的 `userSigServer` 字段
5. 本地提交推送后，GitHub Pages 约 1 分钟自动更新

### 验证

浏览器直接访问 `函数URL?sdkAppId=1600160855&userId=test1`，
看到 `{"code":0,"userSig":"eJyr..."}` 即为成功。
