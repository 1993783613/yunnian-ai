# 云念AI - 响应式网站

> 与想念的人，再通一次视频 —— 让思念留在云端，让陪伴继续。

基于云念AI 真实产品还原的 H5 移动端应用，包含完整的用户流程：创建数字人 → 实时语音/视频通话。

## 项目特点

- **完全还原真实配色**：深蓝黑背景 (#050913) + 青绿色品牌色 (#35e6d0)
- **真实文案**：所有界面文字均来自云念AI 真实产品（558条原文提取）
- **移动端 H5 布局**：桌面端自动以手机框架居中展示
- **11 个完整页面**：首页、登录注册、创作库、创建角色、通话、消息、我的、充值、隐私设置、用户协议、隐私政策
- **零依赖**：纯 HTML + CSS + JS，无需构建工具
- **响应式**：完美适配手机/平板/桌面

## 部署上线指南

### 方案一：Vercel（推荐，免费）

1. 注册 [Vercel](https://vercel.com) 账号
2. 安装 CLI：`npm i -g vercel`
3. 在项目目录执行：
   ```bash
   vercel
   ```
4. 按提示操作，完成后获得 `https://你的项目.vercel.app` 链接
5. 可绑定自定义域名

### 方案二：Netlify（免费，拖拽部署）

1. 访问 [Netlify Drop](https://app.netlify.com/drop)
2. 将整个项目文件夹拖入页面
3. 即时获得在线链接

### 方案三：腾讯云静态网站托管

1. 登录腾讯云控制台 → 静态网站托管
2. 创建环境，上传项目文件
3. 绑定自定义域名（需备案）

### 方案四：GitHub Pages

1. 创建 GitHub 仓库
2. 上传项目文件
3. Settings → Pages → Source 选择 main 分支
4. 访问 `https://用户名.github.io/仓库名`

### 方案五：阿里云 OSS

1. 创建 OSS Bucket，读写权限设为"公共读"
2. 上传项目文件
3. 绑定自定义域名 + CDN 加速

## 自定义修改

### 修改品牌信息

编辑 `index.html` 中的文案和 `css/style.css` 中的设计变量：

```css
:root {
  --brand: #35e6d0;           /* 品牌主色 */
  --bg-darkest: #050913;      /* 最深背景 */
  --text-primary: #ffffff;    /* 主文字色 */
}
```

### 添加真实二维码

替换首页中的占位元素为真实二维码图片：

```html
<img src="./your-qr-code.png" alt="下载二维码">
```

### 接入真实后端

当前为前端展示版。如需接入真实后端：
- 登录接口：替换 `js/app.js` 中的 `handleAuth()`
- 通话功能：接入 WebRTC SDK（如腾讯云 TRTC / 声网 Agora）
- 数字人生成：接入 AI 数字人 API
- 支付：接入微信支付 JSAPI
